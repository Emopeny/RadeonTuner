## 应用简介
RadeonTuner 是 AMD Adrenalin 软件的一个易用替代品，面向只需要基础功能、并且使用「仅驱动」安装类型的用户。

## 应用功能
- 驱动重置后自动重新应用调校设置。
- 支持将设置导入/导出到文件。
- 修改显卡与风扇的调校设置。
- 修改游戏图形设置。
- 修改显示设置。

## 安装说明
1) 将 RadeonTuner 文件夹解压到设备上任意目录。
2) 确认已安装下方列出的全部运行要求。
3) 运行 RadeonTuner 可执行文件。

## 卸载说明
1) 删除解压出的 RadeonTuner 文件夹即可。

## 使用技巧
- 安装驱动时请选择「仅驱动（Driver Only）」软件类型。
- 在「设置」选项卡中启用后，可让窗口保持置顶显示。

## 运行要求
- AMD Radeon 驱动 25.5.1 或更新版本。
- AMD Radeon 驱动为「仅驱动」软件类型。
- AMD Radeon RDNA 或更新架构。
- 已安装 Microsoft .NET Desktop Runtime。
- 已安装 Microsoft Visual C++ Redistributable。
- 需要 Microsoft Windows 10（18362）64 位或更新版本。
